# HR Workforce Analytics Dashboard 📊

## Overview
HR Dashboard built with Power BI analyzing 161 employees 
across 13 Locations, 11 Nationalities & 9 Departments.

## 🔍 Key Insights
- Hiring peaked in 2020 with 82 new employees
- 74% Male | 26% Female workforce
- Production & Sales are the largest departments
- Total Compensation exceeds 3.5M

## 🛠 Tools Used
Power BI | DAX | Data Modeling
